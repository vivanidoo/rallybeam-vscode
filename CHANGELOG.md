# Changelog

All notable changes to the Rallybeam extension. The VS Code Marketplace shows this file on the extension's page.

## 0.2.0

The first stable release. The extension's code is the same as in 0.1.0; this version exists so that **Install** works
without choosing a pre-release. If you installed 0.1.0, you are moved to 0.2.0 by the next update.

## 0.1.0

The first public release, published as a pre-release.

- **Join a meet** from the code canvas (**Open in VS Code**) or with **Rallybeam: Join meet**. The meet's code opens as
  a folder on your disk and stays live with the meet.
- **Live cursors and selections** of everyone in the meet, with their names and colours, plus **Go to someone's
  cursor** and **Follow someone**.
- **One folder per task.** When the interviewer moves to another task, its folder fills with that task's files; the
  earlier task's folder stays as it was left, read-only. **Open the brief** shows the task's text beside the code.
- **Run and Run tests** in Rallybeam's sandbox, visible to the whole meet, or on your own computer for JavaScript and
  TypeScript project types. **Show the app** opens an app's preview in VS Code.
- **Rallybeam panel** in the activity bar, with the inviting company's branding when the meet carries it.
- **Package offer** for JavaScript projects, installing only when you click **Install**, with
  `npm install --ignore-scripts`.
- No telemetry. The extension connects only to Rallybeam.
